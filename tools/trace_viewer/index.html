这一页把「每一帧、每个目标为什么被这样判定」画成一张可点的战场图。

点画面里的框 → 右侧出它的完整链条；点时间轴 → 直接跳到那一帧。

选择 trace.jsonl
  1. 生成：渲染时加 --trace <路径>
  2. 把生成的 trace.jsonl 拖进页面
  3. 点头顶「载入视频」，选 1-8实战.mp4，画面就是真实帧而不是示意图
  4. 要让 FV 播放器联动：FV.exe --http "1-8实战.mp4" 启动，再用 serve.py 打开本页
